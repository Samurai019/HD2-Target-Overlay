# Mod Options Menu v1.0.1 本地指示条修正版

本包是 CowboyBingus 的 [Mod Options Menu](https://github.com/CowboyBingus/ModOptionsMenu) v1.0.1 的本地修改版，不是作者发布的新版本。上游基线提交：4dedb3428b320507a80190dd3a083bd668e84126。

## 安装

退出游戏，在管理器中用 `Mod-Options-Menu-v1.0.1-UI-Fix.zip` 替换原菜单。只启用一份菜单；若原菜单来自合集，请先禁用合集中的菜单选项。保留 Target Overlay 1.1.0 和 Bingus Shared Loader v18+，部署后重启。

本包保留原菜单的保存键、GUID 和配置文件位置，三个标记开关的已应用设置无需重设。

## 修改与依据

用户截图中蓝币显示“开”，但两段指示条均为灰色。Target Overlay 的三项均使用同样的 toggle 声明，没有第三项专用样式。

已有构建采集的原生函数 `17fe7e0` 在 `17fe811` 比较缓存选择索引；索引相同则在 `17fe824` 直接返回，不调用视觉刷新 `17fdf30`。因此复用后的行即使值正确，也可能保留重置后的指示条。此机制与截图相符，尚未取得截图对应行的动态内部状态，不能声称已完成实机原因确认。

修正版只在菜单新建页面行时，先选一个有效的相邻值，再立即选回实际值，强制原生函数刷新指示条。两次调用均作用于菜单控件，发生在同一更新内；不调用菜单 `set`，不修改待应用或保存的设置，不触发选项回调。后续普通切换仍沿用原流程。

独立回归夹具模拟原生“相同索引不刷新”，覆盖 toggle 开/关和四项 choice。删除新增刷新代码后测试失败。作者原有完整菜单仿真在游戏 lua51.dll 中通过，验证页面、应用、取消、保存和恢复；本项目全套52项测试通过。安装包语法、归档完整性和资源内容一致性验证通过。

游戏内第三行白条显示仍需复测；本次没有启动或操作游戏。
