# HD2 Target Overlay

《绝地潜兵 2》（Helldivers 2）小地图目标标记 mod。在原版小地图上叠加虫巢、哨站、支线任务、超级货币、勋章和主线黑匣子的位置，帮助玩家寻找目标。

覆盖层随小地图缩放和平移，仅在打开地图时显示，标记可显示在孢子迷雾上方。游戏数据访问为只读，不修改原版发现状态、任务进度、奖励或迷雾。

当前版本：**1.3.7**（移除F7开关；新增普通和临时刷新频率设置，普通为1–60、临时为1–120次/秒，默认5和60；开始关图时立即清理图标；目标仍每2秒刷新）。

黑匣子定位和拾取后撤销均已通过用户游戏内验证。首次拾取后由原版标记接管，黄色菱形撤销，放下后也不重复显示。HUD 弧度适配已通过游戏内测试。1.2.0 移除了调试采集、F8/F9 和校准参考图形，保留 F7 总开关与四个独立菜单开关。1.3.0 新增默认关闭的勋章开关，1.3.5移除F7并增加频率滑块。

## 功能

| 标记 | 目标 | 撤销条件 |
| --- | --- | --- |
| 红色空心六边形 | 计入原版据点统计的虫巢、机器人哨站、飞碟据点 | 所有据点清除后撤销，发现后继续保留 |
| 红色空心八角星 | 追踪虫巢穴支线 | 支线完成后撤销，发现后继续保留 |
| 白色空心正方形 | 尚未发现的支线任务 | 发现后撤销 |
| 蓝色空心三角形 | 已加载的超级货币模型 | 拾取并销毁模型后撤销 |
| 金色空心八边形与蓝色绶带奖章 | 已加载的勋章模型（默认关闭） | 拾取并销毁模型后撤销 |
| 黄色空心菱形 | 已加载的主线黑匣子模型 | 原版标记出现后撤销，也在模型卸载或销毁后撤销 |

五类标记可以独立开关，目标列表约每 2 秒刷新一轮，每轮在同一次显示更新中完成。打开、关闭、缩小和放大地图时使用临时刷新频率，最后一次操作半秒后恢复普通频率；普通可设为1–60、临时可设为1–120次/秒，默认普通5、临时60；开图检测通常最多约0.1秒，再加查询耗时和帧调度延迟。拾取或完成后的撤销通常最多延迟约2秒。普通小型兴趣点和其他不计入原版据点统计的任务附带地点不显示。超级货币和勋章标记取决于模型是否已加载，无法提前识别远处或封闭容器中尚未生成、加载的货币。

追踪虫巢穴按准确任务资源识别，在任务坐标显示专属红色空心八角星，支线完成后撤销，默认不再叠加白框。关闭“标记虫巢”时，仍可通过“标记支线”显示未发现任务的白框；其他零散虫洞继续排除。

用户已确认关闭HUD弧度时完全对齐。沿用1.1.9验证的适配：读取当前HUD弧度并按校准关系修正覆盖层竖向坐标；关闭弧度时保持原始投影。新版弧度适配已通过游戏内测试。

## 环境要求

- 已核对的游戏构建：**1.8.46015.0**。
- 必需：**Bingus Shared Loader v15 或更新版**。
- 可选：[Mod Options Menu](https://github.com/CowboyBingus/ModOptionsMenu)，用于控制五类标记和两项刷新频率；使用菜单时需要 **Bingus Shared Loader v18 或更新版**。

mod 会校验游戏构建。游戏更新后若校验不符，覆盖层不会运行，需要重新核对兼容性。

## 安装

1. 下载 [Target-Overlay-1.3.7.zip](https://github.com/Samurai019/HD2-Target-Overlay/releases/download/v1.3.7/Target-Overlay-1.3.7.zip)。
2. 退出游戏，使用 mod 管理器导入该 ZIP。
3. 启用 Target Overlay 和 Bingus Shared Loader，部署后重新启动游戏。

升级时替换旧版 Target Overlay，只启用一个版本。若安装过本项目早期的 **Map Icons Display Only** 或 **Map Icon Probe**，请先禁用。

ZIP 内的 `.patch_0` 是供管理器分配槽位的占位文件，请通过管理器安装。

## 使用

进入任务并打开小地图即可查看标记。地图开始关闭时就清理图标，不等待收缩动画结束。F7开关已移除。

安装可选的 Mod Options Menu 后，可在 **暂停菜单 → MODS → TARGET OVERLAY** 中调整：

- **标记虫巢**：控制虫巢、机器人哨站和飞碟据点的红色标记。
- **标记支线**：控制支线任务的白色标记。
- **标记蓝币**：控制超级货币的蓝色标记。
- **标记勋章**：控制金色八边形与蓝色绶带奖章标记，默认关闭。
- **标记黑匣子**：控制主线黑匣子的黄色菱形标记。
- **刷新频率（次/秒）**：整数1–60，默认5。
- **临时提速刷新频率（次/秒）**：整数1–120，默认60；用于打开、关闭和缩放地图，最后一次操作半秒后恢复普通频率。

修改后点击 **APPLY**（默认键盘按键为 **Tab**）生效。已应用的设置由菜单保存，重启后恢复。已有保存的频率保持原值，想使用新的60次/秒默认值请手动调整并APPLY。两项频率控制图标显示更新，不改变每2秒一次的目标查询；实际显示频率受游戏帧率限制。勋章默认关闭，其余四类默认开启；未安装菜单时也保持此默认值，并使用普通5、临时60次/秒。

## 常见问题

**打开地图后没有标记？**

确认已部署 mod、安装所需 Loader 并重启游戏。同时检查游戏构建是否受支持，以及菜单中的对应标记开关是否开启。

**为什么发现目标后标记消失？**

所有据点的红色标记保留到清除，靠近发现不会撤销。支线任务的白色标记仍在发现后撤销。

**为什么没有显示所有超级货币？**

mod 只能定位当前已经加载的超级货币模型，不会提前生成或扫描尚未加载的货币。

## 源码与构建

| 路径 | 内容 |
| --- | --- |
| `src/overlay.lua` | 覆盖层、目标识别和菜单设置 |
| `build_overlay.py` | 生成 Target Overlay 安装包 |
| `dist/` | 各版本安装包及生成的 Lua 文件 |
| `tests/` | 离线回归测试 |
| `research/` | 目标布局、兼容性数据和研究记录 |
| [OVERLAY.md](OVERLAY.md) | 详细使用说明与版本变更 |

使用 Python 3 和提供 LuaJIT 2.1 运行时的 `lupa` 构建：

```sh
python -m pip install lupa
python build_overlay.py
```

当前源码构建 `dist/Target-Overlay-1.3.7.zip` 和 `dist/target_overlay.lua`。此前1.3.3版本用户在游戏构建 6AB3B43F、Watchdog v0.18.0 下反馈：开销降至 10 ms/s 以下，移动和长时间开图不再持续升高。这是该用户环境的实测反馈，不保证所有配置得到相同数值。

离线测试入口：

```sh
python -m unittest discover -s tests -v
```

仓库同时保留早期诊断与实验代码。部分研究脚本和历史测试需要本地游戏数据、二进制采集文件或外部工具，这些文件不随仓库上传。离线测试不代表游戏内验证；菜单显示、实际切换及部分据点行为的验证记录见 [OVERLAY.md](OVERLAY.md)。
